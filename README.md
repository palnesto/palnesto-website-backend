# Palnesto Website Backend

Express + MongoDB backend scaffold for the Palnesto UGC creator flow.

## Routes

- `GET /health`
- `GET /api/plans`
- `POST /api/plans/seed-defaults`
- `GET /api/leads`
- `POST /api/leads`

## Setup

1. Copy `.env.example` to `.env`
2. Set `MONGODB_URI`
3. Install dependencies with `npm install`
4. Run `npm run dev`
